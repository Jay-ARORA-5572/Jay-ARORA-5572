## Features

* Modern, clean, responsive UI
* Tailwind CSS & Angular standalone components
* Dark/Light mode toggle
* Animated sections and smooth scrolling
* Project showcase with dynamic filters
* Blog section for articles or updates
* Services page for client offerings

## ▶ How to Run Locally

### 1. Clone the repository

```
git clone https://github.com/YOUR-USERNAME/jay-portfolio.git
cd jay-portfolio
```

### 2. Install dependencies

```
npm install
```

### 3. Start development

```
ng serve --open
```

## Build for Production

```
ng build
```

Final output will be in `dist/`.
